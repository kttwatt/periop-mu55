## 1) ภาพรวมการประยุกต์ใช้ Navigator

- Navigator = ระบบคอมพิวเตอร์นำวิถี (นำทาง) ตำแหน่งพยาธิสภาพ โดยใช้ภาพจาก X-Ray คอมพิวเตอร์ (CT) ระหว่างผ่าตัด [สไลด์][หน้า 2]
- แนวคิดหลัก: ทำหน้าที่เสมือน **GPS** สร้างแผนที่สมอง 3 มิติแบบเรียลไทม์จากภาพสแกนก่อนผ่าตัด (MRI/CT) แล้วนำทางเครื่องมือศัลยแพทย์ไปยังตำแหน่งที่ถูกต้อง [สไลด์][หน้า 9]
- ใช้ในบริบท **Hybrid Operating Room** ที่ผสานห้องผ่าตัดปกติเข้ากับเทคโนโลยีสร้างภาพขั้นสูง (CT/MRI) เพื่อวินิจฉัยและรักษาในห้องเดียวกันแบบทันที [สไลด์][หน้า 3]
- 8 กลุ่มหัตถการทางประสาทศัลยศาสตร์ที่ใช้ Intra-Operative CT under Navigator [สไลด์][หน้า 7]:
  1. Craniotomy with tumor removal
  2. Craniotomy with AVM resection
  3. Laminectomy with Fixation
  4. Ventriculo-Peritoneal (VP) shunt / Omaya shunt
  5. Endoscopic Ventriculostomy
  6. Transnasal Approach
  7. Deep Brain Stimulation (DBS)
  8. Brain Tumor Biopsy

## 2) Intra-Operative CT + Navigator ใน Hybrid OR

### นิยาม/ลักษณะห้อง
| ประเด็น | รายละเอียด | tag |
|---|---|---|
| นิยาม Hybrid OR | ผสานห้องผ่าตัดแบบดั้งเดิม + เทคโนโลยีสร้างภาพขั้นสูง (CT/MRI) วินิจฉัย-รักษาในห้องเดียวกันทันที | [สไลด์][หน้า 3] |
| ขนาดห้อง/ทีม | ห้องขนาดใหญ่พิเศษ รองรับทีมสหสาขาวิชาชีพ: ศัลยแพทย์ วิสัญญีแพทย์ รังสีแพทย์ พยาบาลห้องผ่าตัด | [สไลด์][หน้า 4] |
| เทคโนโลยี | มี CT + ระบบคอมพิวเตอร์นำวิถี ช่วยผ่าตัดซับซ้อนได้สะดวก แม่นยำ มีประสิทธิภาพขึ้น | [สไลด์][หน้า 4] |
| เตียงผ่าตัด | ปรับองศาได้ ใช้งานได้หลากหลายตามความต้องการศัลยแพทย์แต่ละสาขา | [สไลด์][หน้า 5] |
| อุปกรณ์ในห้อง | เคลื่อนที่ได้สะดวก ไม่ขัดขวางการผ่าตัด | [สไลด์][หน้า 5] |

### ข้อดีของ Intra Operative CT with Navigator (6 ข้อ ตามสไลด์) [สไลด์][หน้า 6]
1. กำหนดเป้าหมายการผ่าตัดแม่นยำแบบ real time + ตรวจสอบเนื้องอกที่อาจหลงเหลือได้ระหว่างผ่าตัด
2. วินิจฉัย+รักษาเกิดขึ้นครั้งเดียวกัน (one visit)
3. หัตถการปลอดภัย (safe procedures) มีประสิทธิภาพมากขึ้น
4. ระยะเวลาผ่าตัดสั้นลง
5. ได้ภาพรังสีระหว่างผ่าตัด
6. เหมาะกับการผ่าตัดซับซ้อน/ผู้ป่วยกลุ่มเสี่ยงสูง

### ขั้นตอนการทำงานของระบบ Navigation (Workflow) [สไลด์][หน้า 10]
| ขั้นตอน | รายละเอียด |
|---|---|
| Pre-operative imaging | สแกน MRI/CT สร้างแผนที่สมอง 3 มิติละเอียด ครอบคลุมเนื้องอก+โครงสร้างรอบข้าง; เทคนิคขั้นสูงเช่น DTI ใช้ทำแผนที่เนื้อขาวสำคัญ (เช่น บริเวณพูด/เคลื่อนไหว) |
| Planning | ทีมศัลยแพทย์ใช้ข้อมูลภาพวางแผนจุดเข้า-ทางเดินผ่าตัดที่หลีกเลี่ยงบริเวณสมองสำคัญ |
| Registration | วางเครื่องหมาย/จุดอ้างอิงบนศีรษะผู้ป่วย หรือติดกรอบพิเศษ เพื่อจัดตำแหน่งผู้ป่วยให้ตรงกับแผนที่ 3 มิติในระบบนำทาง |
| Real-time navigation | จอ Navigator แสดงสมอง+ตำแหน่งเนื้องอกแบบเรียลไทม์ ศัลยแพทย์ใช้ "Probe" ชี้ตำแหน่งแม่นยำ |
| Tumor removal | นำเนื้องอกออกอย่างระมัดระวัง พร้อมปกป้องเนื้อเยื่อสมองปกติ ลดความเสี่ยงภาวะบกพร่องทางระบบประสาท |
| Closure | ปิด/ยึดกระดูกกะโหลก และปิดหนังศีรษะ |

### ขั้นตอนใช้งานจริงในห้องผ่าตัด (ตามลำดับเวลา) [สไลด์][หน้า 11-12]
- **ก่อนผ่าตัด**: ผู้ป่วยไป CT → ศัลยแพทย์นำข้อมูลลงแผ่น CD → โหลดข้อมูลเข้าเครื่อง Navigator → ศัลยแพทย์ register navigator (จับคู่ตำแหน่งพยาธิสภาพผู้ป่วยกับผลอ่าน CT)
- **ระหว่างผ่าตัด**: ศัลยแพทย์ตรวจสอบตำแหน่งเนื้องอกด้วยการใช้ navigator ต่อเนื่อง

## 3) กรณี/หัตถการที่ประยุกต์ใช้ Navigator

### Brain tumor / vascular
| หัตถการ | นิยาม/สาระสำคัญ | tag |
|---|---|---|
| Craniotomy with tumor removal | เปิดกะโหลกศีรษะ+ตัดเนื้องอกออก 3 ขั้น: (1) เปิดกะโหลก – วางยาสลบ เปิดแผลหนังศีรษะ ตัดกระดูกกะโหลกออกชั่วคราว (2) นำเนื้องอกออก – ใช้เครื่องมือพิเศษ+กล้องกำลังขยายสูง ตัดเนื้องอกออกจากเนื้อสมองปกติให้น้อยที่สุด (3) ปิดแผล – นำแผ่นกระดูกกลับยึดด้วยแผ่นโลหะ/สกรู เย็บปิดหนังศีรษะ | [สไลด์][หน้า 8] |
| Craniotomy with AVM resection | AVM (Cerebral Arteriovenous Malformation) = หลอดเลือดแดง-ดำต่อชนกันตรงโดยไม่มีหลอดเลือดฝอยคั่น เสี่ยงโป่งพอง/แตก เลือดออกในสมองอันตรายถึงชีวิต ผ่าตัดเปิดกะโหลกตัดกลุ่มหลอดเลือดขอดออก ร่วมกับ Intraoperative Cerebral Angiogram เพื่อยืนยันว่าตัดออกหมดสมบูรณ์ | [สไลด์][หน้า 13-14] |
| — รายละเอียด Angiogram ระหว่างผ่าตัด | ฉีด contrast media ผ่าน introducer sheath สอดสายสวน (catheter) ทางหลอดเลือดแดงขาหนีบ (femoral artery) ร่วมกับเครื่อง fluoroscope (C-arm) ฉายภาพดูกายวิภาคหลอดเลือดสมอง ยืนยันตำแหน่ง AVM ทั้งก่อน-หลัง resection | [สไลด์][หน้า 15] |
| Brain Tumor Biopsy – Stereotactic biopsy (Frame Link) | เจาะชิ้นเนื้อวินิจฉัยชนิดเนื้องอก เจาะรูกะโหลก ใช้ Needle biopsy ผ่านเนื้อสมอง ใช้ CT ร่วมกับ Navigator บอกตำแหน่งก้อนเนื้องอก แล้วนำชิ้นเนื้อออก | [สไลด์][หน้า 30] |
| Brain Tumor Biopsy – VarioGuide biopsy (Frameless) | ตัดชิ้นเนื้อส่งตรวจ ตำแหน่งเห็นต่อเนื่อง/แม่นยำ ขั้นตอน work flow by step ใช้ง่าย ไม่ต้องใช้ stereotactic frame; ใช้ sure track จับกับ needle biopsy ต่อเข้ากับอุปกรณ์ช่วยผ่าตัด | [สไลด์][หน้า 32] |
| DBS (Deep Brain Stimulation) | ฝังสายกระตุ้นไฟฟ้าอย่างอ่อนที่สมองส่วน Globus Pallidus หรือ Subthalamic nucleus ช่วยผู้ป่วยอาการสั่น/เกร็งเคลื่อนไหวได้ดีขึ้น; ใช้ stereotactic frame ร่วมกับ O-Arm หาตำแหน่ง Subthalamic nucleus ส่วนใหญ่รักษา Parkinson's disease (เสื่อมเซลล์ประสาท → โดปามีนลดลง → คุมกล้ามเนื้อไม่ได้ อาการ: สั่น เกร็ง เคลื่อนไหวช้า เสียการทรงตัว) | [สไลด์][หน้า 26-28] |

### Spine (กระดูกสันหลัง) / O-arm
| หัตถการ | นิยาม/สาระสำคัญ | tag |
|---|---|---|
| Laminectomy with Fixation | เปิดโพรงกระดูกสันหลังลดการกดทับเส้นประสาท (Laminectomy) ร่วมกับใส่สกรู+แท่งโลหะยึดตรึงกระดูกสันหลัง (Fixation) รักษากระดูกสันหลังตีบแคบร่วมกับหลวม/เคลื่อน | [สไลด์][หน้า 16] |
| ประโยชน์ CT navigator/O-arm ในหัตถการ spine | (1) แม่นยำขึ้น ลดอันตรายต่อเส้นประสาท (2) นำทางหาตำแหน่งใส่ instrument (3) ผ่าตัดแม่นยำ ถูกตำแหน่ง ประสิทธิภาพมากขึ้น (4) แผลเล็ก เจ็บปวดน้อย ฟื้นตัวเร็ว | [สไลด์][หน้า 17] |
| O-arm ในการผ่าตัดกระดูกสันหลัง | ศัลยแพทย์เห็นกระดูกสันหลังเป็น 3 มิติ (ความลึก ความสูง ความกว้าง) แบบ real time ระหว่างผ่าตัด | [สไลด์][หน้า 18-19] |

### CSF diversion (Shunt/Ventricular procedures)
| หัตถการ | นิยาม/สาระสำคัญ | tag |
|---|---|---|
| VP Shunt (Ventriculoperitoneal Shunt) | ใส่ท่อระบายน้ำไขสันหลังส่วนเกินจากโพรงสมองลงช่องท้อง รักษาภาวะโพรงสมองคั่งน้ำ ลดความดันในกะโหลก; Navigator ช่วยหาตำแหน่งที่ ventricle เพื่อวางสาย catheter shunt | [สไลด์][หน้า 20-21] |
| Omaya Shunt | ฝังอุปกรณ์ชิ้นเล็กใต้หนังศีรษะ สายสวนขนาดเล็กต่อเข้าโพรงน้ำไขสันหลัง ใช้ให้ยาเคมีบำบัด/ยาปฏิชีวนะโดยตรง และเจาะดูดน้ำไขสันหลังตรวจโดยไม่ต้องแทงเข็มซ้ำ ส่วนใหญ่ใช้ฉีดยาเคมีบำบัดเข้า ventricle ในผู้ป่วยมะเร็งสมอง | [สไลด์][หน้า 22-23] |
| Endoscopic (Third) Ventriculostomy (ETV) | ผ่าตัดเปิดโพรงสมองที่สามด้วยกล้อง endoscope แผลเล็ก รักษาภาวะน้ำในสมองคั่ง (Hydrocephalus) ชนิดอุดตัน โดยสร้างทางเดินใหม่ให้น้ำไขสันหลังระบายออกได้เอง | [สไลด์][หน้า 24] |

### Skull base
| หัตถการ | นิยาม/สาระสำคัญ | tag |
|---|---|---|
| Transnasal Approach with Tumor Removal | ส่องกล้องนำเนื้องอกออกผ่านโพรงจมูก แผลเล็ก ไม่เปิดกะโหลกศีรษะ นิยมใช้รักษาเนื้องอกต่อมใต้สมอง หรือเนื้องอกฐานกะโหลกศีรษะ | [สไลด์][หน้า 25] |

## 4) บทบาทพยาบาล / การเตรียม

| ขั้นตอน | สิ่งที่เกิดขึ้น (จากสไลด์ — เน้นมุมศัลยแพทย์) | บทบาทพยาบาลที่เกี่ยวข้อง | tag |
|---|---|---|---|
| ก่อนผ่าตัด | ผู้ป่วยไป CT → นำข้อมูลลงแผ่น CD → โหลดเข้าเครื่อง Navigator → register ตำแหน่งพยาธิสภาพเข้ากับผล CT | ประสานงาน/ตรวจสอบความพร้อมของข้อมูลภาพและเครื่อง Navigator ก่อนเริ่มผ่าตัด จัดท่าผู้ป่วยและอุปกรณ์ registration (เครื่องหมาย/กรอบอ้างอิง) ให้พร้อม | [สไลด์]+[เสริม] |
| ระหว่างผ่าตัด | ศัลยแพทย์ตรวจสอบตำแหน่งเนื้องอกด้วย navigator ต่อเนื่อง | ดูแลความปลอดเชื้อ (sterility) ของ probe/instrument ที่เชื่อมกับระบบนำวิถี ติดตามจอภาพ/สัญญาณเครื่องร่วมกับทีม เตรียม set อุปกรณ์เฉพาะหัตถการ (เช่น stereotactic frame, VarioGuide, sure track, needle biopsy) ให้ตรงลำดับใช้งาน | [เสริม] |
| ทีมสหสาขาในห้อง | Hybrid OR ทำงานร่วมกันของศัลยแพทย์ วิสัญญีแพทย์ รังสีแพทย์ พยาบาลห้องผ่าตัด | พยาบาลเป็นส่วนหนึ่งของทีมสหสาขาที่ต้องประสานงานรอบเครื่อง CT/Navigator ในห้องขนาดใหญ่ที่มีอุปกรณ์เคลื่อนที่ได้ ต้องระวังไม่ให้อุปกรณ์ขัดขวางการผ่าตัด | [สไลด์][หน้า 4-5] |
| หัตถการ AVM | มีการฉีด contrast media ผ่าน femoral artery ร่วมกับ fluoroscope (C-arm) | เตรียม/ดูแลจุดแทงเข็มบริเวณขาหนีบ (femoral site) ติดตามภาวะแทรกซ้อนจากการฉีด contrast ร่วมกับทีมรังสี | [สไลด์]+[เสริม] |

## 5) จุดที่มักออกสอบ/สับสน

- **Hybrid OR คือห้องผ่าตัดที่ผสาน CT/MRI เข้ากับห้องผ่าตัด** ไม่ใช่แค่ห้องผ่าตัดที่มี C-arm ทั่วไป — จุดเด่นคือวินิจฉัย+รักษาในห้องเดียวแบบ one visit [สไลด์][หน้า 3][หน้า 6]
- **VP Shunt vs Omaya Shunt**: VP shunt ระบายน้ำไขสันหลังจากโพรงสมอง**ลงช่องท้อง**เพื่อรักษา hydrocephalus (ระบายถาวร); Omaya shunt เป็นอ่างเก็บใต้หนังศีรษะต่อเข้าโพรงสมองเพื่อ**ให้ยา/เจาะตรวจซ้ำ**ได้ ไม่ใช่ระบบระบายลงช่องท้อง [สไลด์][หน้า 20][หน้า 22]
- **VP Shunt/Omaya Shunt vs ETV**: shunt ใช้ท่อ/อุปกรณ์ฝังถาวรระบายน้ำ ส่วน ETV คือผ่าตัดส่อง endoscope **เปิดทางเดินใหม่ให้ร่างกายระบายน้ำไขสันหลังได้เอง** โดยไม่ต้องฝังอุปกรณ์ ใช้กับ hydrocephalus ชนิด**อุดตัน**เท่านั้น [สไลด์][หน้า 24]
- **Stereotactic biopsy (Frame Link) vs VarioGuide biopsy (Frameless)**: ต่างกันที่การใช้ stereotactic frame — Frame Link ต้องติดกรอบยึดศีรษะ, VarioGuide ไม่ต้องใช้ frame แต่ยังใช้ sure track + needle biopsy ร่วมกับ Navigator เหมือนกัน [สไลด์][หน้า 29][หน้า 30][หน้า 32]
- **DBS เป้าหมายสมอง 2 ตำแหน่ง**: Globus Pallidus หรือ Subthalamic nucleus — สไลด์ระบุภาพตัวอย่างการหาตำแหน่งด้วย O-Arm เน้นที่ Subthalamic nucleus [สไลด์][หน้า 27-28]
- **Registration ≠ Real-time navigation**: Registration คือขั้นจับคู่ตำแหน่งผู้ป่วยจริงกับแผนที่ 3 มิติ (ใช้จุดอ้างอิง/กรอบ) ทำ**ก่อน**เริ่มนำทางจริง ส่วน Real-time navigation คือขั้นใช้ Probe นำทางระหว่างผ่าตัดจริง — เป็นคนละขั้นตอนในลำดับ workflow เดียวกัน [สไลด์][หน้า 10]
- **AVM angiogram เข้าทางหลอดเลือดแดงขาหนีบ (femoral artery)** ไม่ใช่เส้นเลือดที่ศีรษะ — เป็นจุดที่มักสับสนตำแหน่งการสอดสายสวน [สไลด์][หน้า 15]

## 6) จุดที่พลาดบ่อย + สูตรจำ

| จุดพลาดบ่อย | สูตรจำ |
|---|---|
| สับสนว่า Navigator ทำงานได้เองโดยไม่ต้องมีภาพก่อนผ่าตัด | จำ Workflow 6 ขั้น: **"ภาพ-แผน-จับคู่-นำทาง-ตัด-ปิด"** (Pre-op imaging → Planning → Registration → Real-time navigation → Tumor removal → Closure) [สไลด์][หน้า 10] |
| จำสลับ VP Shunt กับ Omaya Shunt | **"VP = ไป (ระบายไปช่องท้องถาวร), Omaya = แวะ (แวะเติมยา/เจาะตรวจที่อ่างใต้หนังศีรษะ)"** [สไลด์][หน้า 20][หน้า 22] |
| จำสลับ Stereotactic biopsy กับ VarioGuide biopsy | **"มี Frame = Stereotactic, ไม่มี Frame = VarioGuide (Frameless)"** [สไลด์][หน้า 29] |
| ลืมข้อดี Intra-op CT with Navigator ครบ 6 ข้อ | สูตรจำ **"แม่น-ครั้งเดียว-ปลอดภัย-สั้น-เห็นภาพ-ซับซ้อนได้"** = แม่นยำ real time / one visit / safe procedure / เวลาสั้นลง / ได้ภาพรังสีระหว่างผ่าตัด / เหมาะเคสซับซ้อน-เสี่ยงสูง [สไลด์][หน้า 6] |
| จำผิดว่า ETV ต้องฝังอุปกรณ์เหมือน shunt | ETV = **"เจาะทางใหม่ ไม่ฝังของ"** ให้ร่างกายระบายน้ำเอง [สไลด์][หน้า 24] |
| ลืมว่า DBS ต้องใช้ทั้ง stereotactic frame และ O-Arm ร่วมกัน | จำคู่ **"Frame หา + O-Arm ยืนยัน"** ตำแหน่ง Subthalamic nucleus/Globus Pallidus [สไลด์][หน้า 28] |
| สับสนว่า Transnasal approach ใช้รักษาเนื้องอกส่วนใด | จำ **"จมูกพาไปต่อมใต้สมอง/ฐานกะโหลก"** (ไม่เปิดกะโหลก) [สไลด์][หน้า 25] |
| ลืมองค์ประกอบทีมสหสาขาใน Hybrid OR | จำย่อ **"ศ-ว-ร-พ"** = ศัลยแพทย์ วิสัญญีแพทย์ รังสีแพทย์ พยาบาลห้องผ่าตัด [สไลด์][หน้า 4] |
| แยกไม่ออกว่าใครทำ registration ในสไลด์ | สไลด์ระบุชัดว่า **"ศัลยแพทย์"** เป็นผู้ register navigator ไม่ใช่พยาบาล — พยาบาลมีบทบาทสนับสนุน/เตรียมอุปกรณ์ [สไลด์][หน้า 11][เสริม] |
