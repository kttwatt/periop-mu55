1. ภาพรวม/หลักการของ Navigator (เทียบ GPS/ดาวเทียม)

1.1 หลักการทำงาน
  • ประยุกต์นำมาใช้จากระบบที่บอกตำแหน่งต่างๆ บนโลก **GPS (Global Positioning System)** [สไลด์][หน้า 2]
  • อาศัย**ดาวเทียมที่โคจรอยู่**เป็นตัวรับสัญญาณจากจุดที่ต้องการทราบตำแหน่ง จากนั้น**คอมพิวเตอร์ประเมินผล**แสดงตำแหน่งบนแผนที่ซึ่งแสดงบนจอมอนิเตอร์ [สไลด์][หน้า 2]
  • ช่วยในการวางแผนการเดินทางต่างๆ (analogy ของ GPS ทั่วไป) [สไลด์][หน้า 2]
  • แนวคิดนี้ถูกนำมาปรับใช้เป็น Neuronavigator ในห้องผ่าตัด: กล้องอินฟราเรดทำหน้าที่คล้ายดาวเทียม รับตำแหน่งจาก Reference frame ที่ติดผู้ป่วย/เครื่องมือ แล้วคอมพิวเตอร์ประมวลผลซ้อนตำแหน่งบนภาพ CT/MRI 3 มิติของผู้ป่วยแบบเรียลไทม์ [เสริม]

1.3 การประยุกต์ใช้ทางคลินิก

**Navigator for craniotomy / Brain tumor** [สไลด์][หน้า 20]

**Navigator for brain Biopsy** [สไลด์][หน้า 21-22]

---

  • สมองเป็นอวัยวะสำคัญต่อชีวิต การผ่าตัดสมองต้องการความแม่นยำสูง ผิดพลาดน้อยที่สุด [สไลด์][หน้า 19]
  • ใช้ช่วยผ่าตัด: **โรคพาร์กินสัน, โรคเนื้องอกสมอง, โรคฝีในสมอง, โรคทางกระดูกไขสันหลัง** [สไลด์][หน้า 19]
  • ช่วยผ่าตัดตำแหน่งที่ลึก ค้นหายาก และตำแหน่งสำคัญมากๆ เช่น **ใกล้แกนสมอง (brainstem)** [สไลด์][หน้า 19]
  • เพิ่มความแม่นยำในการผ่าตัดให้ศัลยแพทย์
  • ควบคุมและจัดการเนื้องอกออกได้มาก ลดการบาดเจ็บของเนื้อสมองดีให้น้อยที่สุด หลีกเลี่ยงโครงสร้างสมองสำคัญ
  • สร้างภาพเสมือนจริง 3D เห็นตำแหน่งขณะทำผ่าตัด
  • วางแผนการผ่าตัดได้ถูกต้อง
  • ลดความเสี่ยงและภาวะแทรกซ้อนต่างๆ
  • ตัวอย่าง: เนื้องอกสมองใกล้ตำแหน่ง Brainstem
  • เพิ่มความแม่นยำในตำแหน่ง Brain Biopsy
  • กำหนดตำแหน่งที่เหมาะสมของแผลและขนาดของการเปิดกะโหลกศีรษะ
  • ลดการบาดเจ็บเนื้อสมองดี
  • ควบคุมคำนวณความลึกและหยุดได้ตรงตำแหน่งที่ต้องการชิ้นเนื้อ
  • ใช้ในรายที่มีปัญหา **ventricle ตีบแคบ** หรือมีเนื้องอกกดทับ
  • สร้างภาพเสมือนจริง 3D และเห็นตำแหน่งขณะทำผ่าตัด (real time)

2. ข้อดีของ Navigator

---

  • การผ่าตัดมีประสิทธิภาพที่ถูกต้อง แม่นยำ [สไลด์][หน้า 3]
  • เวลาในการผ่าตัดสั้นลงและแผลมีขนาดเล็ก [สไลด์][หน้า 3]
  • ปลอดภัย และลดภาวะแทรกซ้อน [สไลด์][หน้า 3]
  • ผู้ป่วยฟื้นตัวได้เร็วหลังการผ่าตัด [สไลด์][หน้า 3]

4. ขั้นตอนการใช้งานและบำรุงรักษา

4.1 ขั้นตอนการใช้งาน (ภาพรวม flow) [สไลด์][หน้า 23]

ส่งผู้ป่วยไป CT → โหลดข้อมูลผู้ป่วยจากแผ่น CD → แสดงรูป 3 มิติเพื่อกำหนดความสัมพันธ์ผู้ป่วยและเครื่อง → ลงทะเบียนกำหนดความสัมพันธ์คนไข้ (Register) → จัดวางตำแหน่งของ CAMERA → ติดอุปกรณ์ Reference → คลุมผ้าปลอดเชื้อ → ติดอุปกรณ์ Reference ที่ Sterile → ตรวจสอบพิกัดที่ทำผ่าตัด

4.2 ขั้นตอนละเอียด
ขั้นรายละเอียดอ้างอิง
Set up Frameแพทย์จัดท่าผู้ป่วยโดยใช้ **Mayfield** และติด Reference **Active** กับขาจับ Frame โดยหมุนเกลียวให้แน่น<span class="tag">[สไลด์]</span>[หน้า 24]
Set up Cameraจัดตำแหน่งของ Camera ให้อยู่ในตำแหน่งที่สามารถเห็น Reference frame ได้ชัดเจน<span class="tag">[สไลด์]</span>[หน้า 25]
Planning กำหนดจุด (Register) — Choose &amp; Verify Probe (Medtronic)เลือก Probe ยืนยันกับปุ่มด้านข้างของ Reference frame ชนิด Active → แตะปลาย Probe กับมุมด้านในของ Frame พร้อมกด foot switch เพื่อให้เครื่องมือรู้จักกัน เมื่อสำเร็จจะมีเครื่องหมายแสดง<span class="tag">[สไลด์]</span>[หน้า 27]
6. Planning โดยใช้ Surface Matching(Brain lab) ใช้ **Z-touch**<span class="tag">[สไลด์]</span>[หน้า 30]
7. คลุมผ้าปลอดเชื้อทาน้ำยาบริเวณแผลผ่าตัด → สวมถุงพลาสติกปิดขาจับ Reference frame ส่วนที่ไม่ sterile<span class="tag">[สไลด์]</span>[หน้า 31]
8. ติดตั้ง Reference Frame Sterileใส่ Reference Frame ชนิด **Passive** โดยติด **Passive ball** ให้ครบทุกตำแหน่ง แล้วปูทับด้วยผ้าปลอดเชื้อ<span class="tag">[สไลด์]</span>[หน้า 32]
9. ขั้นตอนการใช้งานขณะผ่าตัดใช้ passive ต้องทำการตรวจสอบตำแหน่งก่อนลง Incision และตรวจสอบตำแหน่งขณะผ่าตัด<span class="tag">[สไลด์]</span>[หน้า 33]
4.3 การแสดงผลบนหน้าจอเครื่อง Stealth station [สไลด์][หน้า 34]
สัญลักษณ์ (สี)ความหมาย

เหลืองCamera ไม่สามารถเห็นเครื่องมือ แต่ยังสามารถทำงานได้ ต้องตรวจดูว่ามีสิ่งใดบังหรือไม่
แดงCamera ไม่สามารถเห็นเครื่องมือ และทำงานไม่ได้ ต้องตรวจสอบตำแหน่ง Camera หรือ passive ball ว่ามีปัญหา

4.5 การทำความสะอาดอุปกรณ์

**อุปกรณ์ทั่วไป** [สไลด์][หน้า 41]

**กล้อง** [สไลด์][หน้า 42]

**ข้อควรระวัง** [สไลด์][หน้า 43]

**ทำความสะอาดภายนอกเครื่อง** [สไลด์][หน้า 44]

  • ถอดแยกชิ้นส่วนประกอบต่างๆ ก่อนนำไปทำความสะอาด
  • ทำความสะอาดด้วยสบู่และน้ำ
  • 1. ห้ามนำอุปกรณ์ที่มีไฟฟ้าประกอบอยู่จุ่มลงน้ำ
  • 2. ทำความสะอาดโดยใช้แปรงปัด **ยกเว้นห้ามถู Passive marker**
  • 3. เช็ดอุปกรณ์ด้วยน้ำยาฆ่าเชื้อโรค
  • ทำความสะอาดเลนส์ก่อนใช้งานในแต่ละครั้ง
  • ใช้ผ้าสำหรับเช็ดเลนส์เท่านั้น
  • ตัวกล้องใช้น้ำยาฆ่าเชื้อโรคเช็ดได้ แต่ระวังไม่ให้น้ำไหลเข้าไปในตัวกล้อง
  • 1. ก่อนปิดสวิตช์ไฟ ต้องปฏิบัติตามขั้นตอนก่อนการเลิกใช้เครื่องมือ (system shut down procedure — สไลด์พิมพ์ว่า "shunt down") [สไลด์]
  • 2. ระวังไม่ให้น้ำหรือของเหลวเข้าไปในเครื่อง หากสงสัยว่ามีน้ำเข้าไป ให้ปิดเครื่องและปล่อยให้เครื่องแห้งก่อนตรวจสอบเครื่องมือ
  • 1. ปิดสวิตซ์ไฟและถอดปลั๊กที่เชื่อม cart ทั้งสองส่วนออกจากกัน
  • 2. ทำความสะอาดเช็ดสายไฟต่างๆ ก่อนเก็บสายไฟเข้าที่
  • 3. เช็ดทำความสะอาดจอภาพด้วยผ้านุ่มชุบน้ำหมาดๆ หรือสบู่อ่อน **ห้ามใช้น้ำยาประเภทลบหรือขจัดคราบสกปรก (solvent) ใดๆ กับจอภาพ**
4.6 การทำให้ปลอดเชื้อ (Component sterilization) [สไลด์][หน้า 45]

ก่อนนำอุปกรณ์ไปทำให้ปลอดเชื้อ ต้องถอดชิ้นส่วนประกอบต่างๆ ออกจากกัน

---

  • 1. ETO (Ethylene oxide) Gas Sterilization
  • 2. Sterrad (Hydro peroxide) Gas Sterilization
  • 3. Steam Sterilization (Autoclave) — **ยกเว้น Passive marker** และหากไม่เร่งด่วนหรือจำเป็นไม่แนะนำ เนื่องจากทำให้อายุการใช้งานลดลง

5. บทบาทพยาบาล (สรุป/สังเคราะห์จากขั้นตอนในสไลด์)

---

  • เตรียมอุปกรณ์ Navigator ให้ครบก่อนเริ่มผ่าตัด (System hardware, Camera, Reference frame ทั้ง 2 ชนิด, Probe ทั้ง 2 ชนิด, Passive ball, CD ข้อมูลผู้ป่วย) [เสริม] (อิงรายการอุปกรณ์ [สไลด์][หน้า 8-18])
  • ร่วมกับแพทย์ในขั้นตอน **Set up Frame**: ช่วยจัดท่าผู้ป่วยด้วย Mayfield และดูแลการยึด Reference Active กับขาจับ Frame ให้แน่น [เสริม] (อิง [สไลด์][หน้า 24])
  • ช่วยจัดตำแหน่งกล้องให้เห็น Reference frame ชัดเจนตลอดการผ่าตัด [เสริม] (อิง [สไลด์][หน้า 25])
  • ปฏิบัติตามลำดับการคลุมผ้าปลอดเชื้อ: ทาน้ำยาบริเวณแผล → สวมถุงพลาสติกปิดขาจับส่วนที่ไม่ sterile → ติด Passive ball ให้ครบทุกตำแหน่งก่อนปูผ้าปลอดเชื้อทับ [สไลด์][หน้า 31-32]
  • คอยสังเกตสัญลักษณ์สีบนจอระหว่างผ่าตัด (เขียว/เหลือง/แดง) และแจ้งทีมทันทีหากมีสิ่งบังกล้องหรือ probe [เสริม] (อิง [สไลด์][หน้า 34])
  • ดูแลการทำความสะอาดและทำให้ปลอดเชื้อของอุปกรณ์หลังใช้งานตามขั้นตอนที่ถูกต้อง โดยเฉพาะข้อห้ามเกี่ยวกับ Passive marker (ห้ามถู, ห้าม autoclave) [สไลด์][หน้า 41, 45]
  • ปฏิบัติตาม system shut down procedure ก่อนปิดเครื่องทุกครั้ง และระวังไม่ให้ของเหลวเข้าเครื่อง [สไลด์][หน้า 43]

6. จุดที่มักออกสอบ/สับสน

---

  • **Reference Frame มี 2 ชนิด**: Active (ติดก่อนผ่าตัด กับขาจับ Mayfield) vs Passive (ติด Passive ball ใช้ตอน sterile ในสนามผ่าตัด) — ต้องแยกให้ออกว่าอันไหนใช้ตอนไหน [สไลด์][หน้า 10, 11, 24, 32]
  • **Probe ก็มี 2 ชนิด** เช่นกัน (Active, Passive) — สไลด์สะกดหัวข้อที่ 6 ผิดเป็น "**Prove** (Passive)" ระวังคำถามหลอกเรื่องการสะกด [สไลด์][หน้า 14]
  • **Z-touch** คือการลงทะเบียนแบบ touchless ด้วยการรับรู้อัตโนมัติของการสะท้อนแสงเลเซอร์โดยกล้องอินฟราเรด — ต่างจาก Probe แบบที่ต้องสัมผัสจุดอ้างอิง [สไลด์][หน้า 12, 30]
  • **สัญลักษณ์สีบนจอ**: เหลืองกับแดงต่างกันตรงที่ "ยังทำงานได้หรือไม่" (เหลือง = ยังทำงานได้ / แดง = ทำงานไม่ได้) [สไลด์][หน้า 34]
  • เครื่อง Navigator ที่ศิริราชมี **2 ยี่ห้อ**: Brainlab และ Medtronic Stealth Station (รุ่น S7, S8) [สไลด์][หน้า 4]
  • **Shunt placement** ใช้ระบบ Electromagnetic (AxiEM) ที่ "**No head pin**" — ต่างจาก craniotomy ทั่วไปที่ต้องใช้ Mayfield pin ยึดศีรษะ [สไลด์][หน้า 38]
  • วิธีทำให้ปลอดเชื้อมี 3 วิธี (ETO, Sterrad, Steam/Autoclave) — **Passive marker ห้ามทำ Steam Sterilization (Autoclave)** [สไลด์][หน้า 45]

7. จุดที่พลาดบ่อย + สูตรจำสั้น

จุดที่พลาดบ่อย
  • สับสนระหว่าง "ห้ามถู Passive marker" (ขั้นทำความสะอาดด้วยแปรง) กับ "ห้าม Autoclave Passive marker" (ขั้นทำให้ปลอดเชื้อ) — เป็นข้อห้ามคนละขั้นตอนแต่เกี่ยวกับอุปกรณ์เดียวกัน [สไลด์][หน้า 41, 45]
  • ลืมว่าเลนส์กล้องต้องเช็ดด้วย**ผ้าเช็ดเลนส์เฉพาะ**เท่านั้น ส่วนตัวกล้อง (ภายนอก) เช็ดด้วยน้ำยาฆ่าเชื้อโรคได้ [สไลด์][หน้า 42]
  • เข้าใจผิดว่า Reference **Active** ใช้ตลอดการผ่าตัด — จริงๆ Active ติดตอน set up frame ก่อนเข้าสนามปลอดเชื้อ ส่วน **Passive** (พร้อม Passive ball) คือชนิดที่ใช้ในสนามปลอดเชื้อระหว่างผ่าตัดจริง [สไลด์][หน้า 24, 32]
สูตรจำสั้น
  • **"เขียวเห็นชัด เหลืองยังไหว แดงต้องหยุดเช็ค"** — จำความหมายสัญลักษณ์สีบนจอ [เสริม]
  • **"Active ก่อนคลุมผ้า, Passive ในสนามปลอดเชื้อ"** — จำชนิด Reference frame ตามลำดับการใช้งาน [เสริม]
  • **"3 สะอาด 3 ปลอดเชื้อ"** — ทำความสะอาด = สบู่+น้ำ / แปรงปัด / น้ำยาฆ่าเชื้อ, ทำให้ปลอดเชื้อ = ETO / Sterrad / Autoclave (ยกเว้น Passive marker ห้าม autoclave) [เสริม]
