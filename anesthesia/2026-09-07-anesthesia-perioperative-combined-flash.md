**23. การเคลื่อนไหว**
   2 = ขยับได้ดีทั้งแขนและขา / 1 = ขยับแขนหรือขาได้ / 0 = ไม่ขยับทั้งแขนและขา  — [3. Postoperative patient care [สไลด์]]

**24. การหายใจ**

**25. การไหลเวียนเลือด**
   2 = ความดันเลือดแตกต่างจากค่าเดิมไม่เกิน 20 มม.ปรอท / 1 = แตกต่าง 20-50 มม.ปรอท / 0 = แตกต่างมากกว่า 50 มม.ปรอท  — [3. Postoperative patient care [สไลด์]]

**26. ความรู้สึกตัว**
   2 = ตื่นดี / 1 = ปลุกตื่นได้ง่าย / 0 = ปลุกไม่ตื่น ไม่ตอบสนอง  — [3. Postoperative patient care [สไลด์]]

**27. ความอิ่มตัวของออกซิเจนในเลือด**
   2 = มากกว่า 92% เมื่อหายใจอากาศปกติ (FiO2 = 0.21) / 1 = มากกว่า 90% เมื่อใช้ O2 เข้มข้นสูง / 0 = น้อยกว่า 90% แม้ใช้ O2 เข้มข้นสูง  — [3. Postoperative patient care [สไลด์]]

**28. สัญญาณชีพ**
   2 = แตกต่างจากค่าเดิมไม่เกิน 20% / 1 = แตกต่าง 20-40% / 0 = แตกต่างมากกว่า 40%  — [3. Postoperative patient care [สไลด์]]

**29. การเคลื่อนไหว**
   2 = เดินได้ปกติ ไม่เวียนศีรษะ / 1 = เดินได้โดยมีคนช่วย / 0 = ลุกเดินไม่ได้  — [3. Postoperative patient care [สไลด์]]

**30. คลื่นไส้อาเจียน**
   2 = เล็กน้อย รักษาได้ด้วยยากิน / 1 = ปานกลาง รักษาได้ด้วยยาฉีด / 0 = รุนแรง ยังมีอาการแม้ได้ยาฉีดซ้ำ  — [3. Postoperative patient care [สไลด์]]

**31. ความปวด**
   2 = เล็กน้อย ควบคุมได้ด้วยยากินแก้ปวด / 1 = ปวดมาก ไม่สามารถควบคุมได้ด้วยยากินแก้ปวด  — [3. Postoperative patient care [สไลด์]]

**32. ปริมาณเลือดออกจากแผลผ่าตัด**
